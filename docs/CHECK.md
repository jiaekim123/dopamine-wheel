## B. v1.4 spec 변경 검증

### 연출 강도 토글 삭제
- ☑ Home 화면에 Full/Soft/Off 토글이 **없음** (삭제 확인) — Home 캡처 어디에도 토글 UI 없음
- △ 모든 게임에서 항상 Full 강도 연출 적용 (플래시·셰이크·슬로우모션·컨페티 모두 활성) — 경주마만 시연. 옵션 자체가 없으므로 경로 검증은 OK
- ☑ 새로고침 후 localStorage에서 `motionLevel` 키 없음 — `JSON.parse(localStorage.getItem('dopamine_wheel_v1'))` 결과 `{lastInput, lastK, lastMode, lastRanks}`만 존재

### KCounter 자유 입력
- ☑ "당첨자 수" 아래에 `1 ≤ k < n` 안내 문구 **없음** — 안내 문구 없이 카운터만 표시
- ☑ `+` 버튼이 상한 없이 계속 증가 가능 (예: n=3에서도 k=10까지 가능) — n=7에서 k=9까지 클릭으로 도달 확인
- ☑ k ≥ n 또는 n < 2 일 때 빨간 경고 텍스트 + 숫자 색이 amber로 — n=7·k=9에서 "당첨자 수가 참가자(7명)와 같거나 많아 게임이 성립하지 않습니다." + 숫자 빨간색
- ☑ 경고 상태에서 게임 카드는 비활성 (`isGameStartable` 차단) — 경고 상태에서 카드 채도 30% + "당첨자 수는 1 이상 6 이하여야 합니다." 인라인 안내
